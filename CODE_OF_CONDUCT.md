# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of conduct. The full text is maintained upstream at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

A plain-text mirror is available at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt

## Scope

The Contributor Covenant applies to all project spaces, including the GitHub repository (issues, pull requests, discussions, code review), the documentation site, any official chat or mailing list, and any public space where someone is representing pedotri.

## Reporting

Reports of unacceptable behaviour can be sent privately to **`ieee802@yandex.ru`** with the subject line `[pedotri CoC]`. All reports are handled confidentially. The maintainer will acknowledge receipt within 7 days and respond with a determination within 30 days.

Reporters will not be retaliated against for filing a good-faith report, and the identity of a reporter will not be shared without their consent except as required by law.

## Enforcement

The maintainer is responsible for clarifying and enforcing standards of acceptable behaviour and will take appropriate and fair corrective action in response to any behaviour that they deem inappropriate. Enforcement follows the Contributor Covenant's [Community Impact Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) (correction → warning → temporary ban → permanent ban).
